[^_^]: # 'Ha-ha-ha'

### Description:

This is a training project for mastering automated testing :woman_student:

### Requirements:

* Linux, macOS, WSL
* Git
* PHP >= 8.3
* Composer
* Make
* Xdebug
 
### Installation:

1. Cloning the repository

```sh
 git clone git@github.com:XXMargoRitaXX/LetsLearnAutomatedTesting.git
```

2. Changing to the LetsLearnAutomatedTesting directory

```sh
 cd LetsLearnAutomatedTesting
```

3. Installing dependencies

```sh
 make install
```

4. Running tests

```sh
 make test
```
